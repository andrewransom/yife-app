# Yife.app

Yife.app is a responsive campaign knowledge-management web app for tabletop roleplaying games.

It helps Game Masters and players organize campaign information in one place, including characters, sessions, quests, NPCs, locations, factions, plot arcs, encounters, timeline events, and notes.

The MVP focuses on fast, dense, role-aware workflows for capturing, linking, browsing, and updating campaign knowledge, with rich text notes and section-based visibility controls.
