# Entities And Fields

Yife organizes campaign information into compact records for quick lookup. Short facts belong in fields near the top of a record. Longer prose, secrets, prep, table notes, and theories belong in Details, GM Details, character journals, or notes.

## Characters

Characters are player characters in the campaign.

Use fields for name, status, controlling player, pronouns, species or ancestry, class progress, Character Sheet link, short summaries, quick stats, and hooks. Use Details for the visible character description, Backstory for owner-and-GM material, GM Notes for hidden context, and Journal for private character thoughts.

Hooks are short character knives, goals, obligations, or unresolved prompts. A hook can be promoted into a Storyline when it becomes campaign-facing.

## NPCs

NPCs are non-player characters.

Use fields for name, apparent status, true status, role, speech reminder, relationship to the party, faction, known and true locations, reporting line, short summaries, and GM-only quick statblocks. Use Details for player-visible canon and GM Details for motives, secrets, plans, and hidden truth.

## Parties

Parties are groups of characters.

Use fields for name, status, member characters, active member flags, home location, current location, short summaries, color, and symbol. Use Details for the group description and GM Notes for private campaign context. Funds and resources are separate party or character records, not party description text.

## Factions

Factions are organizations, crews, institutions, or power groups.

Use fields for name, status, parent faction, type, scope, numbers, party disposition, relationship to the party, headquarters, territory, leader, public goal, true GM goal, color, and symbol. Some facts can be hidden from players until revealed. Use Details for public faction information and GM Details for history, ideology, secrets, operations, and internal politics.

## Locations

Locations are places in the campaign world.

Use fields for name, type, status, parent location, known/visited flags, relationship to the party, disposition, controlling faction, owner or steward, ruler or authority, population, size, terrain, danger, accessibility, color, and symbol. Use Details for player-visible location description and GM Details for secrets, hazards, room notes, travel notes, and hidden context.

## Storylines

Storylines are quests, threads, and arcs.

Use fields for title, Storyline type, category, status, parent Storyline, major flag, priority, short summaries, primary location, reward, completion timestamp, color, and symbol. A quest is a Storyline marked as Quest. A major parent Storyline can represent an arc. Use Details for player-visible Storyline information and GM Details for clues, complications, hidden outcomes, and planning.

Players can create shared Storylines for group-maintained threads or private Storylines for personal reminders, subject to campaign permissions.

## Sessions

Sessions are planned or completed game sessions.

Use fields for date, session number, optional title, local start and end time, status, short summaries, and next-session teaser. Use Session Notes for recap or table notes, GM Prep for agenda and planned scenes, and GM Private Notes for scratchpad material.

## Encounters

Encounters are lightweight planned gameplay situations.

Use fields for optional title, type, status, related session, related Storyline, difficulty, order, color, and GM reference image when media support exists. Use GM Prep for setup, tactical reminders, clues, and prep context. Use Outcomes for results and consequences.

Encounter statblocks are GM-only quick references. They can track quantity and optional individual HP/defeated state, but they are not a combat tracker.

## Timeline Events

Timeline Events are dated moments in campaign history or play.

Use fields for title, date text, sort key, event type, related session, short summaries, primary location, color, and symbol. Use Details for visible event context and GM Details for consequences, secrets, disputed details, and hidden context.

The date text is human-readable. The sort key is for manual ordering when the date text cannot be sorted automatically.
